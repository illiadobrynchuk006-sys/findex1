Цей каталог призначений для текстового корпусу.

Згенеруйте 1000 демонстраційних документів командою:
python scripts/generate_demo_corpus.py

Демонстраційні файли з'являться у data/demo/.
Або розмістіть власні UTF-8 .txt документи у data/books/.
Корпусні документи не зберігаються у Git, щоб не захаращувати репозиторій.
